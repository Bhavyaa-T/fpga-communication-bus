For SSH using a DHCP server, we can no longer use a static ip address. 

On the board, back up the existing configuration:

cp /etc/network/interfaces /etc/network/interfaces.backup

Edit the network configuration:

nano /etc/network/interfaces

Set its contents to:

auto lo
iface lo inet loopback

auto eth0
iface eth0 inet dhcp 

This means that now the board is a dhcp client and will be assigned an ip address by the server. 

for this to work, we also have to change the MAC address by configuring ethaddr during U-boot:

- setenv ethaddr <MAC ADDRESS> // use a MAC address from the list below
- saveenv
