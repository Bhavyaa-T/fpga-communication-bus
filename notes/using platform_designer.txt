Platform designer is an application that can be accessed from quartus prime. 

Main things to note:

- IP on LHS, select IP as required, modify parameters and make connections 

- Generate HDL, noting that it will create a folder with the name you chose for this module 

- If re-generating, select the parent directory of the already created module_name folder, such that it overwrites the previous HDL generated

- An instance of the module with all ports defined can be found in module_name called module_name_inst 

- copy this code into your top level module to use it 

PIOs:

- PIOs can be configured as bidirectional, input, output, or inout. 

- first thing to understand is the addressing. Upon importing a PIO we see that a base and end address is set. 

- For the C programming part, only the base address is really relevant, as it gives us our offset from the relevant axi bus base address

- However, for reference, note that it is 16 bytes wide (0x0 - 0xf), as by default there are 4 registers, each taking 4 bytes of address space: data, direction, interruptmask, edgecapture.

- data sits from 0x0 - 0x4, direction from 0x4 to 0x8, interruptmask from 0x8 to 0xC, edgecapture from 0xC to 0xf
